# kedgeway site

Marketing and docs site for kedgeway. Next.js (App Router), TypeScript, hand-written CSS with custom properties and CSS Modules.

Brand system (colors, type, layout rules, motion): see [BRAND.md](./BRAND.md).

## Commands

```sh
npm install        # install dependencies
npm run dev        # dev server at http://localhost:3000
npm run build      # production build (all pages prerender)
npm run start      # serve the production build
npx tsc --noEmit   # type check
```

## Structure

- `src/app/page.tsx`: landing page
- `src/app/docs/page.tsx`: long-form docs
- `src/app/icon.svg/route.ts`: favicon generated from the horse sprite
- `src/components/`: `Mark` (static pixel-grid horse), `HorseGallop` (client, gallop cycle), `EcosystemGrid` (client), `Reveal` (client)
- `src/data/horse.ts`: gallop frames generated by `scripts/rasterize-horse.ts` from Muybridge's public-domain "The Horse in Motion" (run `npx tsx scripts/rasterize-horse.ts <sheet.jpg>`; not run at build); `src/data/ecosystem.ts`: Scout counts with a sum assertion
- `src/app/globals.css`: design tokens

Only `EcosystemGrid`, `HorseGallop` and `Reveal` are client components.

## Deploy

Vercel, zero config.
